# Data Quality and Exploratory Analysis

**Track:** Data Analytics
**Level:** Beginner-friendly
**Estimated time:** 45–60 minutes

## What you need to make

Audit and clean a customer churn dataset, then document the quality decisions and initial patterns.

## Passing checklist

- [ ] Profile columns, data types, missing values, outliers, and duplicates.
- [ ] Clean the data with documented assumptions and validation checks.
- [ ] Calculate summary statistics and inspect meaningful distributions.
- [ ] Put the work and a short explanation in one public or view-only link.

## What to submit

Submit one public or view-only link. Put supporting files in the same repository, folder, or project page so one link is enough.

## Optional portfolio upgrade

Export the clean dataset and a data dictionary.

## Supplied material

- [Customer churn dataset](https://edvyro.in/datasets/customer_churn_sample.csv) — Synthetic customer records for cleaning and exploratory analysis.

## Submission example

Share one GitHub repository, Google Drive folder, Figma file, YouTube video, or portfolio page that a reviewer can open without requesting access.
